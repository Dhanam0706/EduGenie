## Customer Journey Map

| Phase of Journey | Stage 1: Start | Stage 2: Learn | Stage 3: Check and Plan |
|---|---|---|---|
| **Actions** <br> What does the customer do? | - Opens EduGenie in the browser<br>- Chooses a task from the dropdown | - Types a question or topic, or pastes notes<br>- Submits and reads the answer, explanation or summary<br>- Asks a follow-up question | - Generates a quiz and answers it<br>- Reads the corrected answers<br>- Requests a learning path for the next topic |
| **Touchpoint** <br> What part of the service do they interact with? | - Web page: task dropdown and text area | - Gemini-powered question, explanation and summary features | - Quiz buttons with instant feedback<br>- Learning path result |
| **Customer Thought** <br> What is the customer thinking? | - "Is this easy to use?"<br>- "Will it understand my topic?" | - "Is this answer correct and simple enough?"<br>- "Can I ask more about it?" | - "Do I really know this?"<br>- "What should I study next?" |
| **Customer Feeling** <br> What is the customer feeling? | Curious, slightly unsure | Relieved when the explanation is clear | Confident, motivated |
| **Process Ownership** <br> Who is in the lead on this? | Frontend ({{member4}}) | AI modules and backend ({{member2}}, {{member3}}) | Quiz and learning path modules, testing ({{member2}}, {{member5}}) |
| **Opportunities** <br> How can we improve this stage? | - Add example topic suggestions<br>- Add voice input | - Show answers with formatting and diagrams<br>- Support more languages | - Track quiz scores over time<br>- Adapt the next quiz to weak areas |
